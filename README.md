ДЗ 9. TodoBox
Реалізуйте простий Todo-додаток із можливістю додавати та видаляти нотатки.
📁 src/TodoBox.jsx
Основний компонент, який відображає форму для додавання нової нотатки та показує список усіх нотаток на екрані.
Початковий HTML — layout.html
📁 src/Item.jsx
Відображає окремий елемент списку.
Приймає такі властивості:
task
onRemove
HTML із доданими нотатками — layout2.html
Додавання елементів відбувається у зворотному порядку — нові нотатки завжди з’являються зверху.
Підказки:
Для отримання нового id використовуйте функцію uniqueId.
