ДЗ 10. RSuite + JSONPlaceholder (Albums/Photos)
В якості виконаного ДЗ обов'якового треба здати
Діаграму взаємодії компонентів (як я малюю на уроках) - робити тут draw.io вона повинна містити в собі всю візуалізацію того того як взаємодіють ваші компоненти і місця звідки беруться дані, починаючи з App.jsx
Виконане ДЗ відповідно діаграми.
------------
Реалізувати односторінковий застосунок на React з використанням RSuite, який працює з API JSONPlaceholder:
Albums: https://jsonplaceholder.typicode.com/albums
Photos: https://jsonplaceholder.typicode.com/photos?albumId={id}

Що потрібно зробити
Завантажити список альбомів і відобразити його у вигляді бокової панелі (sidebar) з використанням компонентів RSuite.
Додати пошук/фільтр альбомів:
пошук по title,
опціонально фільтр по id.
При кліку на альбом — завантажувати фотографії відповідного альбому.
Відобразити фото у вигляді ґріда/карток з мініатюрами.
Показувати стан завантаження та помилки за допомогою компонентів RSuite (Loader, Message, Placeholder).
Клік по фото відкриває Modal з великим зображенням.
У модалці реалізувати кнопки Next / Prev для навігації між фото.
Кешувати фото альбомів у локальному стані (щоб повторно не фетчити альбом, який уже завантажений).
Стан зберігати у верхньому компоненті (App) та прокидувати вниз через пропси — без Redux та глобальних сторів.
Розділити застосунок на логічні компоненти:
AlbumSidebar
PhotoGrid
PhotoModal
(опціонально) Header
Вимоги до структури та архітектури
Один екран (SPA без роутера).
Використання RSuite UI Library для UI.
Жодного Redux або інших state managers — тільки useState/useEffect.
Стан (вибраний альбом, кеш фото, фільтри, відкритий модал) зберігається на рівні App.
Компоненти не повинні тягнути дані напряму з API — фетчить тільки App.
Що має вийти в результаті
Зліва — список альбомів з пошуком.
Справа — ґрід фото вибраного альбому.
При кліку — модалка з великою картинкою і навігацією.
Усі завантаження/помилки — красиво оформлені RSuite-компонентами.
Чистий поділ на компоненти + нормальне прокидування стану вниз.
Додаткові завдання (необов’язково)
Зберігати вибраний альбом та фільтр у localStorage.
Зробити клієнтську пагінацію для фото (наприклад, показувати по 20).
Додати skeleton placeholder для фото перед завантаженням.
